# Product Requirements Document

## Project Title
AI-Powered Text Summarizer Web Application

## Objective
Build a Flask web application that allows users to upload a TXT file and receive an AI-generated summary using the Groq API.

## Target Users
Students, professionals, and general users who need quick summaries of text documents.

## Core Features
- Upload a TXT file
- Read and display original file content
- Send text content to the Groq LLM API
- Display summarized output
- Handle upload errors and empty files

## Technical Approach
The application will use Python with Flask for the web server. Users will upload TXT files through an HTML form. Flask will read the uploaded file, send the text to Groq using the Groq Python SDK, and return a concise summary.
